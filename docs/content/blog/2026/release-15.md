[Release 15](https://github.com/kjgcoop/taskfiend/releases/tag/v15.0.0) has no overarching theme; it's whatever tickled my fancy.

Upgrading requires both `npm run build` and `php artisan migrate`.

Highlights: morning email notifications (inline digest or PNG), near-real-time change alerts, search in comments, notes on project reminders, parent/child tasks that span projects, the parent visible in the task sidebar, and assorted polish to templates and exports. The full list is on [GitHub](https://github.com/kjgcoop/taskfiend/releases/tag/v15.0.0).
