---
title: "Differences from Todoist"
---

This was originally planned as an almost Todoist clone. It's been a while since I used Todoist, so my recollection is foggy. This is what I remember off the top of my head:

- I wasn't happy with how it handled multiple users, which is why I set about making a near clone. I can't speak to the finer points of how they differ because I don't remember. But they are different. 
- Comments are instance-specific — use them for notes about that particular occurrence
- If today you complete a daily task scheduled for yesterday, the next iteration is today. Todoist always has the next iteration in the future.
- If you specify the date Thursday on Thursday, this software will give you the day seven days from now. Todoist reads it as today.
