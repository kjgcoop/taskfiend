---
title: "Intentionally Missing Features"
---

There are some features that are pretty standard to to-do list software that I've intentionally omitted. I find I spend a lot of time entering data without actually benefitting from said data entry. It becomes a sort of navel-gazing. Because I don't know if there are any other users, I'm creating this software as though I'm the center of the world.
 
- Priorities
- Inter-task relationships (blockers, dependencies, etc) - as of v9, there's a section in each task that lists other tasks that that link back to the task you're looking at. This is about as close as I plan to get.
- Multiple dates (due date vs show on date) - I intentionally named the `tasks`' date field `date` as opposed to `due_date`. I don't know if you want to use it as a day on which you can start the task, or the day on which the task is due. Now you get to choose your own adventure.
- Kanban - I <333333 kanban, but I'm trying to keep this simple. For more complicated projects, I use and recommend [Vikunja](https://vikunja.io/). I'm not affiliated with them, just a fan.
- Sync with Google calendar - I barely trust myself not to accidentally delete things from my calendar, I certianly don't want other entities having the opportunity to do so.
