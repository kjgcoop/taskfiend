Here are some templates you can import into Task Fiend if you find that idea amusing.

1. [Emergency Preparedness Review template](/templates/taskfiend_template_Emergency_Preparedness_Review.zip) - I spin up this project twice a year. 
2. [Trip template](/templates/taskfiend_template_Trip.zip)
3. [Setting up a new Domain Name template](/templates/taskfiend_template_New_Domain_Name.zip) - I definitely don't register domain names so often that I need this. This is strictly an intellectual exercise. I made it just for you. You're welcome.
4. [Tarot Project template](/templates/taskfiend_template_Tarot_Project.zip) - one task for each card of the Rider-Waite deck.
5. [Preparing for a House Guest template](/templates/taskfiend_template_Prep_for_a_House_Guest.zip) - advises creating a project from a housekeeping template. I don't plan to share this template because it's so specific to my house, but you can probably create one for your own household easily enough.
